# 📋 Product Vision - Floating MD

> **تاريخ التحديث:** 2026-01-26  
> **الحالة:** 🔒 مستند مرجعي - يُعتمد قبل أي تعديل  
> **الهدف:** توثيق الرؤية النهائية للمنتج لمنع الانحراف عن المسار

---

## 🎯 الرؤية الأساسية

**Floating MD** هو شريط أدوات عائم **موحد** (Unified Floating Toolbar) يتحول بين وضعين:
1. **وضع الشريط (Toolbar Mode):** شريط رفيع ملتصق بالحافة.
2. **وضع المحرر (Editor Mode):** لوحة ماركداون كاملة، الشريط هو الـ Header.

> ⚠️ **ملاحظة حرجة:** لا توجد نوافذ منفصلة! البرنامج = نافذة واحدة تتحول.

---

## 🔄 سيناريو الاستخدام

### الحالة 1: استخدام الشريط فقط
```
[البرنامج يبدأ] → [شريط عمودي ملتصق باليمين أو اليسار]
                  → [المستخدم يستخدم أزرار: نسخ، لصق، حذف، إلخ]
                  → [الشريط يختفي تلقائياً عند عدم الاستخدام]
```

### الحالة 2: فتح لوحة الماركداون
```
[المستخدم يضغط زر M] 
    → [الشريط يتحول لأفقي تلقائياً إذا كان عمودياً]
    → [الشريط يصبح Header للوحة]
    → [تظهر منطقة المحتوى تحته (Textarea/Preview)]
    → [يظهر شريط أدوات ثانوي: عين (معاينة/تحرير)، تكبير]
```

### الحالة 3: إغلاق لوحة الماركداون
```
[المستخدم يضغط زر M مرة أخرى أو زر إغلاق]
    → [اللوحة تختفي]
    → [الشريط يعود لوضعه ومكانه السابق (عمودي/أفقي)]
```

## 🧩 مكونات الواجهة

### 1. الشريط الرئيسي (Main Toolbar)
**الأزرار:**
| الترتيب | الزر | الوظيفة |
|---------|------|---------|
| 1 | 📋 Copy | نسخ (Ctrl+C) |
| 2 | 📋 Paste | لصق (Ctrl+V) |
| 3 | ✂️ Cut | قص (Ctrl+X) |
| 4 | ☑️ Select All | تحديد الكل |
| 5 | 🗑️ Delete | حذف |
| 6 | 🕒 History | سجل الحافظة |
| --- | Separator | --- |
| 7 | Ⓜ️ Markdown | فتح/إغلاق لوحة المحرر |
| 8 | ✨ Sparkle | تنظيف نص AI |
| --- | Separator | --- |
| 9 | 👁️ Pin | تثبيت (منع الإخفاء) |
| 10 | ✖️ Quit | إغلاق البرنامج |

### 2. شريط أدوات المحرر (Editor Toolbar)
**يظهر فقط عند فتح لوحة الماركداون:**
| الزر | الوظيفة |
|------|---------|
| 👁️ عين | التبديل بين وضع التحرير ووضع المعاينة |
| 📋 Load | تحميل من الحافظة |
| 📤 Copy HTML | نسخ كـ HTML منسق |
| 🔳 Snap/Resize | فتح قائمة تحجيم Windows 11 Style |

### 3. منطقة المحتوى (Content Area)
- **وضع التحرير:** Textarea بخط Mono.
- **وضع المعاينة:** HTML منسق مع دعم RTL.

## 📐 سلوك النافذة

### الالتصاق (Docking)
| الحافة | الشكل | السلوك |
|--------|-------|--------|
| يمين | عمودي | ينزلق حراً على المحور Y |
| يسار | عمودي | ينزلق حراً على المحور Y |
| أعلى | أفقي | ينزلق حراً على المحور X |

> ❌ **ممنوع:** الطفو في منتصف الشاشة أو الالتصاق بالأسفل (Taskbar).

### تذكر الموضع
- البرنامج يحفظ آخر موضع وحجم عند الإغلاق.
- عند إعادة التشغيل، يعود لنفس المكان.

### Single Instance
- نسخة واحدة فقط من البرنامج تعمل.
- إذا فُتحت نسخة جديدة، تقتل القديمة وتأخذ مكانها.

---

## 🚫 ما لا يجب فعله

1. ❌ **لا تنشئ نوافذ منفصلة** للمحرر أو أي ميزة أخرى.
2. ❌ **لا تجعل الشريط يطفو** في منتصف الشاشة.
3. ❌ **لا تسرق التركيز** (Focus) من النافذة النشطة.
4. ❌ **لا تغير التصميم** بدون موافقة المطور الكتابية.

---

## ✅ معايير القبول (Acceptance Criteria)

- [ ] البرنامج نافذة واحدة فقط.
- [ ] زر M يحول الشريط للوحة الماركداون.
- [ ] الشريط = Header للوحة.
- [ ] أدوات المحرر تظهر عند الحاجة.
- [ ] Focus Guardian يعمل.
- [ ] الموضع والحجم يُحفظ.
