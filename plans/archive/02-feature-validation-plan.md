## 🧪 خطوات الاختبار

### المرحلة 1: اختبار الأزرار الأساسية
1. [ ] فتح Notepad وكتابة نص
2. [ ] تحديد النص في Notepad
3. [ ] الضغط على زر **Cut** في الشريط ← هل اختفى النص من Notepad؟
4. [ ] الضغط على زر **Paste** ← هل عاد النص؟
5. [ ] الضغط على زر **Delete** ← هل حُذف الحرف/التحديد؟

### المرحلة 2: اختبار Focus Guardian
1. [ ] فتح VS Code وكتابة كود
2. [ ] الضغط على أي زر في الشريط
3. [ ] هل VS Code ما زال نشطاً (Title Bar ملون)؟
4. [ ] هل الكتابة تستمر في VS Code بدون مشاكل؟

### المرحلة 3: اختبار Smart Scrub
1. [ ] نسخ نص من ChatGPT يحتوي على "Here is the code:"
2. [ ] الضغط على زر **✨ Sparkle**
3. [ ] لصق النص ← هل اختفت المقدمة؟

### المرحلة 4: اختبار Markdown Editor
1. [ ] الضغط على زر **M** ← هل تفتح النافذة؟
2. [ ] كتابة `# عنوان` ← هل يظهر بشكل صحيح في Preview؟
3. [ ] الضغط على **Load from Clipboard** ← هل يظهر النص؟
4. [ ] الضغط على **Copy HTML** ← لصق في Word، هل التنسيق صحيح؟

### المرحلة 5: اختبار History
1. [ ] نسخ 3 نصوص مختلفة
2. [ ] الضغط على زر **🕒 History** ← هل تظهر القائمة؟
3. [ ] اختيار نص قديم ← هل يتم لصقه؟
