# 🧪 Manual Testing Checklist

## 1. Focus Management
- [ ] افتح ملف نصي (Notepad) واكتب شيئاً.
- [ ] افتح Floating MD.
- [ ] انسخ نصاً من Notepad.
- [ ] اضغط Paste في الشريط.
- [ ] تأكد أن Notepad ما زال نشطاً (Window Title Bar ملون) ولم يفقد التركيز.

## 2. Window Docking & Auto-Hide
- [ ] اسحب الشريط لأقصى اليمين. هل يلتصق ويصبح عمودياً؟
- [ ] اسحب الشريط لأقصى الأعلى. هل يلتصق ويصبح أفقياً؟
- [ ] اضغط زر **Pin** (👁️). هل يبقى الشريط ظاهراً دائماً؟
- [ ] ألغِ **Pin** وابعد الماوس. هل يختفي الشريط (يصبح شفافاً وصغيراً)؟
- [ ] مرر الماوس فوقه مرة أخرى. هل يظهر بسرعة؟

## 3. Smart Scrub (AI Cleaning)
- [ ] انسخ نصاً من ChatGPT يحتوي على "Sure! Here is the code you asked for:".
- [ ] انسخ الكود معه.
- [ ] اضغط زر ✨ Sparkle في الشريط.
- [ ] الصق النتيجة في Notepad. هل اختفت المقدمة وبقي الكود فقط؟

## 4. Clipboard History
- [ ] انسخ 3 نصوص مختلفة (مثال: "Test 1", "Test 2", "Test 3").
- [ ] اضغط زر History (أيقونة الساعة 🕒).
- [ ] هل تظهر القائمة بآخر النصوص؟
- [ ] اختر "Test 2". هل تم لصقه تلقائياً؟

## 5. Markdown Editor
- [ ] اضغط زر Markdown (M).
- [ ] هل تفتح النافذة بجوار الشريط مباشرة؟ (وليس في وسط الشاشة).
- [ ] حرك الشريط لمكان آخر واضغط M مرة أخرى. هل تتبع النافذة الشريط؟
- [ ] اضغط "Load from Clipboard". هل يظهر النص الموجود في الحافظة؟
- [ ] اكتب بعض الماركداون (`# Hello`). اضغط "Preview". هل يظهر بشكل جميل؟
- [ ] اضغط "Copy HTML". الصق في مكان يقبل HTML (مثل Word/Outlook). هل يظهر بتنسيق صحيح؟
